- **Hydra admits only named callers.** A NetworkPolicy restricts Hydra's admin port to the gateway and `hydraCallers.admin`, and its public port to `hydraCallers.public`; previously any pod could reach the unauthenticated admin API and accept a login as anyone. `createMcpGateway` now requires `hydraCallers`. The inert `SERVE_TLS_ALLOW_TERMINATION_FROM=0.0.0.0/0` is removed, since Hydra reads it only when it terminates TLS itself.
