- **Tokens issued to other relying parties are refused.** A token is accepted only when its client is registered with the gateway's `PUBLIC_URL` as an audience, so an access token Hydra issued to another service of the same issuer can no longer reach a backend with the user's stored credentials. A token that names no client is refused as well. Existing self-registered clients need the audience added before this deploys; see the pull request for the command.
