- **Proxied MCP streams are no longer cut at 15 seconds.** The proxy had shared the 15-second client used for one-shot calls, and that timeout covers the response body, so SSE streams and slow tool calls were dropped mid-response. It now has its own client with a connect timeout and a five-minute idle timeout per read. Expired sessions and abandoned logins are swept hourly instead of accumulating forever, `/login` shares the callback's rate limit, backend MCP sessions opened by the dashboard are ended on every exit path including a cancelled request, the dashboard reads each credential once instead of two or three times, and SIGTERM now stops the process after a five-second drain rather than waiting for SIGKILL.
